# UnRAR source mirror

A mirror of RARLAB's UnRAR source archive, unchanged, attached to this repository's
[v7.2.1 release](https://github.com/JVK3R/unrar-source/releases/tag/v7.2.1):

    unrarsrc-7.2.1.tar.gz  sha256 3fe3b4d710da45521625353dc2e023dad48c010f02a93302756e1061a8f3ae8e

[PS5 React](https://github.com/JVK3R/ps5-react) builds its RAR extractor from it. The original download is
at [rarlab.com](https://www.rarlab.com/rar_add.htm); this copy is kept so builds do not stop when that site
cannot be reached. UnRAR is © Alexander Roshal. Its license, `license.txt` here and inside the archive, allows
the source to be distributed. Nothing here is modified.
